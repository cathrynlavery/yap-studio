# Security policy

Report a security issue privately through this repository's
[GitHub security advisories](https://github.com/cathrynlavery/yap-studio/security/advisories/new).
Include the affected version, steps to reproduce, impact and a possible fix
if you have one. Do not put a vulnerability in a public issue or pull request.

The maintainer will review the report privately and coordinate a fix and
disclosure through the advisory.

Only the latest release receives security fixes.
