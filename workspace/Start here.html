Yap Studio

Turn a take you filmed into a finished video.

You pick the look and the footage. Claude Code or Codex edits: the story, captions, cards and music. You watch it and leave comments, and the next version follows.

Your video files stay on your computer. Still frames from pinned notes and contact sheets of your clips go to Anthropic when you use Claude Code, or OpenAI when you use Codex, along with the transcript, your notes and the project files your agent reads, as part of your Claude Code or Codex session. ElevenLabs, WaveSpeed and Pexels get only what they need, and only if you turn them on.

Start

  1. Open this folder in Claude Code or Codex

    The folder this page is in. Keep it on this Mac, not in a folder that syncs to the cloud.

  2. Type this to Claude Code or Codex
    set me up

The plain Claude chat app and ChatGPT cannot edit these videos. Use Claude Code or Codex.

Claude Code or Codex asks before it installs anything. On a Mac it may ask you to install Homebrew first, for ffmpeg and Node. The first setup downloads the speech model (about 2.5 GB) and the video renderer. When it is done, Yap Studio opens in your browser and takes it from there.

What you need

  • A Mac or a Linux computerOn a Mac, macOS 14 or newer. Apple silicon is the tested setup.
  • Claude Code, signed in, or Codex, signed inInstall Claude Code and type /login once, or install Codex and sign in.
  • About 10 GB free on this diskPlus room for your videos.
  • A take filmed uprightFrom your phone or camera. Your originals are never changed.
