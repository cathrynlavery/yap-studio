# Code of conduct

Be respectful in issues, pull requests and other project spaces. Welcome people
with different experience and backgrounds. Discuss the work, give useful feedback
and respect a person's decision to end a conversation.

Harassment, threats, discrimination, sexual attention and publishing someone's
private information without permission are unacceptable.

## Reporting

Contact the repository owner through the contact links on the
[maintainer's GitHub profile](https://github.com/cathrynlavery).
For abuse on GitHub, use [GitHub's private reporting form](https://support.github.com/contact/report-abuse).
If you cannot reach the maintainer privately, open an issue asking for a private
contact method without posting incident details or personal information.

For a software vulnerability, follow [SECURITY.md](SECURITY.md).

## Enforcement

The maintainer reviews reports, respects the reporter's privacy and may remove
content, issue a warning or restrict participation. Serious or repeated violations
may result in a ban. These rules apply to everyone, including maintainers.
